# Mon journal de cybersécurité

## 22/11/2026, Offensive Security et Defensive Security Intro (TryHackMe)
- Appris : la sécurité offensive consiste à simuler les actions d'un pirate pour trouver les failles avant lui.
           la sécurité défensive consiste a enquêter sur le hacker en le suivant a la trace et trouver son addresse ip pour pouvoir le stopper. 
- Mot nouveau : pentest
